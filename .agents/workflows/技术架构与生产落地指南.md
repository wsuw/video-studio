# 💻 VideoAgent 技术架构与生产落地指南 (v1.0)

> **核心宗旨：** 全自主是“玩具”，受控流水线才是“工具”。  
> **设计初衷：** 通过工业化流程实现 “低成本纠错” 与 “高确定性产出”。基于源码实测，本项目深度整合了 Next.js 15+、LangGraph 与 CopilotKit v2。

---

## 一、 系统底座：自下而上的四层架构

VideoAgent 采用严格的分层架构，明确“模型抽象、状态编排、复杂任务代理与工具通信”的边界。

### 第一层：基础组件与抽象层 (LangChain + Ollama)
*   **多模型适配**：后端核心采用 `ChatOllama` (默认模型 `gemma4:26b`)，通过 LangChain 实现模型调用的抽象。
*   **结构化输出解析 (Output Parsers)**：在 `agent/src/utils/nodes.py` 中，通过工具调用与 `A2UI` 指令实现强制的结构化输出，确保模型输出机器可读。

### 第二层：状态机与编排引擎 (LangGraph)
*   **显式状态管理**：在 `agent/main.py` 中使用 `StateGraph(AgentState)` 定义工作流。
*   **Checkpointing**：利用 LangGraph 的持久化机制，通过 `langgraph-api` 实现任务的长时运行与故障恢复。
*   **双向同步**：通过 `CopilotKitMiddleware` 与 `StateStreamingMiddleware`，将后端的 `AgentState` 实时流式传输至前端。

### 第三层：高阶任务代理层 (Deep Agents / CopilotKit v2)
*   **A2UI (Agent-to-User Interface)**：这是系统的核心黑科技。智能体通过调用 `generate_a2ui` 工具，动态生成包含图表 (Recharts)、表格 (TanStack Table) 和复杂布局的仪表盘。
*   **状态隔离**：后端 Agent 独立运行在 LangGraph 服务中（默认 `localhost:8123`），前端通过 `/api/copilotkit` 路由作为中继进行通信。

### 第四层：外部执行与通信层 (MCP 协议)
*   **MCP (Model Context Protocol)**：在 `src/app/api/copilotkit/[[...slug]]/route.ts` 中，系统支持 HTTP 类型的 MCP Server 挂载，实现执行层与推理层的安全解耦。

## 二、 前后端技术落地详情 (Source-Verified)

### 2.1 前端：响应式工作台 (Next.js 15+ & CopilotKit v2)
*   **核心框架**：Next.js 15+ (App Router)，全量使用 TypeScript 开发。
*   **AI 交互控制**：
    *   `CopilotKit` (v2): 顶层 Provider，负责管理与后端的 Runtime 通信。
    *   `useAgent`: 用于在 UI 组件中实时订阅 Agent 的运行状态。
    *   `useFrontendTool`: 允许 Agent 直接调用前端定义的 UI 交互动作。
*   **视觉呈现**：
    *   **布局**：TailwindCSS 4 + shadcn/ui，搭配 `Instrument Sans` 与 `JetBrains Mono` 字体提供 Premium 感官。
    *   **渲染器**：使用 `@copilotkit/a2ui-renderer` 动态解析后端返回的 UI Schema。

### 2.2 后端：有状态 Agent 服务 (Python & LangGraph)
*   **环境管理**：使用 `uv` 进行依赖管理，确保 `langchain` (1.2.15) 与 `langgraph` (1.1.6) 环境的严格一致性。
*   **Agent 逻辑**：
    *   在 `agent/src/utils/nodes.py` 中定义 `agent` 节点，配置 `parallel_tool_calls: False` 以增强推理的确定性。
    *   集成 `StateStreamingMiddleware`，实现针对特定 Key (如 `todos`) 的精准状态增量更新。

### 2.3 关键集成机制：The Bridge
*   **Runtime API**：前端 `/api/copilotkit` 使用 `CopilotRuntime` 与 `LangGraphAgent`。
*   **部署模式**：前端 Next.js 服务通过环境变量 `AGENT_URL` (LangGraph API) 与后端 Agent 服务解耦，支持跨服务器扩展。

## 三、 核心管线的技术实现机制

### 3.1 剧本拆解与布局提取 (Design)
*   **技术落地**：利用 `LayoutGPT` 模式将文学描述转化为 `(x, y, w, h)` 坐标。Agent 通过 `generate_a2ui` 实时向用户展示预构图。

### 3.2 渲染调度与容错 (Generation)
*   **Durable Execution**：利用 LangGraph 的 `interrupt` 原语，在渲染等重体力活前强制进入 HITL (人在回路) 审批。

### 3.3 多智能体自动纠错 (Redesign / GENMAC)
*   **GENMAC 架构**：通过条件边 (Conditional Edges) 建立反馈循环。如果 VLM 验证节点发现不一致，则路由回修正节点并携带详细的报错 Trace。

---

## 四、 生产级工程实践红线

1.  **状态精简**：全局 `AgentState` 需控制大小，大型文件仅存储在外部存储（如 S3）并在状态中引用路径。
2.  **工具强约束**：所有工具必须有严格的 `Pydantic` 验证和详尽的 `Docstrings`，禁止模型“盲猜”参数。
3.  **可观测性**：全面集成 **LangSmith**，实现从 Trace (追踪) 到 Cost (成本监控) 的闭环。

# 🎬 VideoAgent 北极星架构指南 (North Star Architecture Guide)

> **版本：** 1.0 (Final Core Edition)  
> **核心宗旨：** 全自主是“玩具”，受控流水线才是“工具”。  
> **设计初衷：** 在算力昂贵、模型存在随机性的当下，通过工业化流程实现 **“低成本纠错”** 与 **“高确定性产出”**。

---

## 🏛️ 第一部分：核心哲学 (Core Philosophies)

### 1. 导演-助理模式 (Director-Agent Synergy)
*   **AI 定位**：系统中 Agent 不是独立的创作主体，而是**“高级助理 (Expert Staff)”**。它负责执行繁琐的计算（Bounding Box 坐标）、逻辑扩写（Logline 演进）和工具调用。
*   **人类定位**：用户是唯一的**“导演 (Director)”**。人类不参与重复体力活，但在每一个核心决策点（Snapshot）拥有绝对的“点头/摇头”终审权。

### 2. 精力分配法则 (80/20 Rule)
*   系统开发与用户交互的 **80% 精力** 必须投入在 **“两头”**：即极度细化的**前期拆解 (Design)** 与极其严苛的**后期质检 (Redesign)**。
*   中间的 **20%**（视频生成 Generation）被视为自动化算力黑盒，应尽量实现无感化、异步化。

### 3. 可追溯的确定性 (Traceable Determinism)
*   任何一帧画面的生成都必须有据可查。如果成品出现穿帮，系统必须能溯源到是哪个“分镜 JSON”或哪一段“提示词参数”出现了偏差，而不是盲目重新抽卡。

## 🔄 第二部分：电影工业管线与 Agent 节点映射

### 阶段一：前期开发 (Design Node) —— 剧本的“分子级”解剖
**哲学要义：** 地基不牢，渲染徒劳。禁止直接从文本跨越到视频。

1.  **分级演进 (Gradual Evolution)**：强制约束 AI 遵循电影工业标准：
    *   `Logline (核心悬念)` → `Synopsis (梗概)` → `Treatment (纲要)` → `Locked Script (锁定脚本)`。
2.  **结构化提取 (Structured Extraction)**：利用 **Deep Agents** 与 **LayoutGPT**，将文学语言转化为机器参数：
    *   **提取要素**：角色 ID 档案、动作向量、全局光影 Key、每一帧的 Bbox 坐标。
3.  **第一道防线 (HITL 审批)**：
    *   > [!TIP]
    *   利用 LangGraph 的 `interrupt()` 原语，在渲染前强制向导演展示“视觉分镜草图”。确认无误后，脚本即被“锁定”，作为后续所有部门的法定执行依据。

### 阶段二：正式摄制 (Generation Node) —— 算力黑盒与指令转化
**哲学要义：** 将创意意图精确“翻译”为引擎参数。

1.  **指令下发 (Instruction Dispatch)**：
    *   利用 **MCP (模型上下文协议)**，将导演意图安全地隔离地下发给底层的 ComfyUI 渲染集群。
2.  **持久化休眠 (Durable Execution)**：
    *   渲染是重体力活。LangGraph 必须执行 **Checkpointing (存档)** 并进入休眠，释放内存资源。系统必须支持 Webhook 回调唤醒，确保长达数十分钟的任务不会导致连接中断。

### 阶段三：后期质检 (Redesign Node) —— 针对“漂移”的防御闭环
**哲学要义：** 放弃“单次生成即完美”的幻想，建立反馈回路。

1.  **VLM 质检员 (Automated QC)**：
    *   利用视觉大模型严格对比“锁定脚本”与“生成素材”。检查关键要素：角色人数、物体位移逻辑、物理规律。
2.  **自路由纠错 (Self-routing Correction)**：
    *   **一致性问题** → 路由至 `Identity Agent` 修改 IP-Adapter 参数。
    *   **构图问题** → 路由至 `Layout Agent` 修改 Bbox 坐标。
    *   **仅局部重绘**：严禁无脑重跑整个镜头，必须实现针对错误片段的“原子化重绘”。

### 阶段四：合成与衍生 (Distribution Node) —— 工业级成片
**哲学要义：** 碎片化素材的工业化缝合。

1.  **自动化多轨合成**：
    *   通过 MCP 封装的 **FFmpeg** 自动完成配音 (TTS)、环境音 (SFX)、字幕与画面轨道的精准对齐。
2.  **多平台适配**：
    *   自动提取“视觉锚点”，将 16:9 原始素材智能剪裁为 9:16 短视频，并自动提取 Hooks 制作预告片。

## 🛠️ 第三部分：技术红线 (Technical Constraints)

*   **禁止：** 让模型在没有任何中间状态（如 JSON/Bbox）的情况下直接生成长视频。
*   **必须：** 所有的 Tool 调用必须通过 **MCP** 以保证环境安全与工具可扩展性。
*   **必须：** 关键环节必须支持 **Human-in-the-Loop (HITL)**，这是系统从“玩具”变为“生产力工具”的标志。
